| Medium | Stack  
  
## Problem  
  
You are given a string `s` containing lowercase letters and `*`.  
  
For every `*`:  
- Remove the star  
- Remove the closest non-star character to its left  
  
Return the string after all stars have been removed.  
  
---  
  
## Approach  
  
Use a **character array as a stack**.  
  
Maintain a pointer `j` that represents the next position to insert a character.  
  
For each character:  
1. If the character is `*`, decrease `j` to remove the previous character.  
2. Otherwise, store the character at index `j`.  
3. Move `j` forward.  
  
Finally return characters from index `0` to `j`.  
  
Essentially:  
  
```  
'*' → pop previous character  
letter → push into array  
```  
  
---  
## Time Complexity  

O(n)  
  
---  
## Space Complexity  
  
O(1)  

---
## Java Solution  
  
```java  
class Solution {  
	public String removeStars(String s) {  
		char[] arr = s.toCharArray();  
		int j = 0;  
		for(int i = 0; i < s.length(); i++){  
			if(arr[i] == '*'){  
				j--;  
			}  
			else{  
				arr[j] = arr[i];  
				j++;  
			}  
		}  
	return new String(arr, 0, j);  
	}  
}  
```
