Approach  
Use the **Reversal Algorithm**.  
  
Steps:  
1. Reverse the entire array.  
2. Reverse the first `k` elements.  
3. Reverse the remaining `n-k` elements.  
  
This effectively moves the last `k` elements to the front.

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;
        reverse(nums, 0, n-1);
        reverse(nums, 0, k-1);
        reverse(nums, k, n-1);
    }
    private void reverse(int[] nums, int l, int r){
        while(l < r){
            int t = nums[l];
            nums[l] = nums[r];
            nums[r] = t;
            l++;
            r--;
        }
    }
}
```
