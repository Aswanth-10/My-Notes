Approach  
1. Traverse from the right to find the **first decreasing element** `i` where  
`nums[i] < nums[i+1]`.  
  
2. If such an index exists:  
- Find the element just larger than `nums[i]` from the right.  
- Swap them.  
  
3. Reverse the subarray from `i+1` to the end to get the **next smallest permutation**.  
  
This ensures the next permutation is just slightly larger than the current one.

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length-1;
        int i = n-1;
        while(i>=0 && nums[i]>=nums[i+1]){
            i--;
        }
        if(i>=0){
            int j = n;
            while(nums[j]<=nums[i]){
                j--;
            }
            swap(nums, i, j);
        }
        reverse(nums, i+1);
    }
    private void reverse(int[] nums, int i){
        int j = nums.length-1;
        while(i<j){
            swap(nums, i, j);
            i++;
            j--;
        }
    }
    private void swap(int[] nums, int i, int j){
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```
