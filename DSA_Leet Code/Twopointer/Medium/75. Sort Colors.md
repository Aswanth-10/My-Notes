Approach  
Use the **Dutch National Flag Algorithm**.  
  
Maintain three pointers:  
  
- `l` → boundary for 0s  
- `m` → current element  
- `r` → boundary for 2s  
  
Rules:  
- If `nums[m] == 0` → swap with `l`, move `l` and `m`  
- If `nums[m] == 1` → move `m`  
- If `nums[m] == 2` → swap with `r`, move `r`  
  
This partitions the array into three regions.

```java
class Solution {
    public void sortColors(int[] nums) {
        int l = 0;
        int r = nums.length-1;
        int m = 0;
        while(m<=r){
            if(nums[m]==0){
                int t = nums[l];
                nums[l] = nums[m];
                nums[m] = t;
                m++;
                l++;
            }
            else if(nums[m] == 1){
                m++;
            }
            else{
                int t = nums[r];
                nums[r] = nums[m]; 
                nums[m] = t;
                r--;
            }
        }
    }
}
```
