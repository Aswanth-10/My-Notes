Approach  
Use **Floyd’s Cycle Detection Algorithm (Tortoise and Hare)**.  
  
- Maintain two pointers:  
- `slow` → moves one step  
- `fast` → moves two steps  
- Each step calculates the **sum of squares of digits**.  
- If the number becomes `1`, it is a happy number.  
- If `slow` meets `fast`, a cycle exists → not happy.

```java

class Solution {
    public boolean isHappy(int n) {
        int s = n;
        int f = n;
        do{
            s = square(s);
            f = square(square(f));
        }while(s != f);

        return s == 1;
    }
    private int square(int x){
        int s = 0;
        while(x != 0){
            int d = x%10;
            s += d*d;
            x /= 10;
        }
        return s;
    }
}
```
