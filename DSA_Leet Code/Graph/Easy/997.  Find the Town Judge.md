## Problem  
In a town of `n` people labeled `1` to `n`, there may be a **town judge**.  

The judge:  
1. Trusts nobody    
2. Is trusted by everyone else (n-1 people)  
  
You are given:

trust[i] = [a, b] → person a trusts person b

Return the label of the judge, or `-1` if none exists.  
  
---  
## Approach  
  
Use **indegree and outdegree arrays**.  
  
- `indegree[i]` → number of people who trust `i`  
- `outdegree[i]` → number of people `i` trusts  
  
Steps:  
  
1. Traverse `trust`:
	indegree[b]++  
	outdegree[a]++
	
2. Find person where:
	indegree[i] == n - 1  
	outdegree[i] == 0
	
---
```java
class Solution {
    public int findJudge(int n, int[][] trust) {
        int[] indegree = new int[n+1];
        int[] outdegree = new int[n+1];

        for(int[] i : trust){
            indegree[i[1]]++;
            outdegree[i[0]]++;
        }

        for(int i = 1; i<=n ;i++){
            if(indegree[i]==n-1 && outdegree[i]==0) return i;
        }
        return -1;
    }
}
```
