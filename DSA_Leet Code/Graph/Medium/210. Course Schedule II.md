## Problem  
There are `numCourses` courses labeled from `0` to `numCourses - 1`.  
You are given `prerequisites`:

[a, b] → take course b before a

Return **any valid order** of courses to finish all courses.  
  
If it is not possible (cycle exists), return an empty array.  
  
---  
## Approach  
  
Use **Kahn’s Algorithm (BFS Topological Sort)**.  
### Steps  

1. Build adjacency list:  b → a
2. Compute indegree array:  indegree[i] = number of prerequisites for course i
3. Push all nodes with `indegree = 0` into queue  
4. Process queue:  
	- Pop node  
	- Add to result  
	- R educe indegree of neighbors  
	- Push new zero-indegree nodes  
5. If all nodes processed → valid order    
   Else → cycle exists → return empty array  

---
```java
class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        LinkedList<Integer>[] AL = new LinkedList[numCourses];

        for(int i = 0; i<numCourses; i++){
            AL[i] = new LinkedList<>();
        }

        for(int[] i : prerequisites){
            AL[i[1]].add(i[0]);
        }

        int[] indegree = new int[numCourses];

        for(int i = 0; i<numCourses; i++){
            for(int v : AL[i]){
                indegree[v]++;
            }
        }

        Queue<Integer> q = new LinkedList<>();
        int[] topo = new int[numCourses];
        int n = 0;
        int c = 0;

        for(int i = 0; i<numCourses; i++){
            if(indegree[i] == 0){
                q.add(i);
            }
        }

        while(!q.isEmpty()){

            int node = q.poll();
            topo[n++] = node;
            c++;

            for(int v : AL[node]){
                indegree[v]--;
                if(indegree[v] == 0){
                    q.add(v);
                }
            }
        }

        return (c == numCourses)?topo: new int[0];
    }
}
```
