## Problem  
You are given a directed graph with `n` nodes.  
  
Each edge:

[u, v, w] → signal travels from u to v in time w

Starting from node `k`, return the time it takes for all nodes to receive the signal.  
  
If not all nodes are reachable → return `-1`.  
  
---  
  
## Approach (Bellman-Ford)  
  
We relax all edges **n-1 times**.  
  
Steps:  
  
1. Initialize distances:
	dist[k] = 0  
	others = ∞
2. Repeat `n-1` times:  
	- For every edge (u → v):
		dist[v] = min(dist[v], dist[u] + w)
3. Find maximum distance  
4. If any node is unreachable → return `-1`  
  
---
```java
class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        int[] result = new int[n + 1];
        Arrays.fill(result, Integer.MAX_VALUE);
        result[k] = 0;

        for (int i = 1; i < n; i++) {
            for (int[] edge : times) {
                int src = edge[0];
                int dst = edge[1];
                int wt = edge[2];

                if (result[src] != Integer.MAX_VALUE && result[src] + wt < result[dst]) {
                    result[dst] = result[src] + wt;
                }

            }
        }

        int ans = 0;
        for (int i = 1; i <= n; i++) {
            if (result[i] == Integer.MAX_VALUE)
                return -1;
            ans = Math.max(ans, result[i]);
        }

        return ans;
    }
}
```
