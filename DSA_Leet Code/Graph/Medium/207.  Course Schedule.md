## Problem  

There are `numCourses` courses labeled from `0` to `numCourses - 1`.  
  
You are given `prerequisites` where:

[a, b] → to take course a, you must first take course b
  
Return `true` if you can finish all courses, otherwise return `false`.  
  
---  
## Approach  
  
Use **Kahn’s Algorithm (BFS Topological Sort)**.  
  
Steps:  
  
1. Build an **adjacency list**: b → a
2. Compute **indegree[]**:  
     - indegree[i] = number of prerequisites for course `i`  
3. Add all nodes with **indegree = 0** into a queue  
4. Process:  
	- Remove node from queue  
	- Reduce indegree of neighbors  
	- Add new zero-indegree nodes to queue  
5. Count processed nodes  
  
---  
## Key Idea  

If all nodes are processed → **no cycle exists**    
If not → **cycle exists → cannot finish courses**  
  
---
```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        LinkedList<Integer>[] AL = new LinkedList[numCourses];
        for(int i = 0; i<numCourses; i++){
            AL[i] = new LinkedList<>();
        }

        for(int[] i : prerequisites){
            AL[i[1]].add(i[0]);
        }

        int[] indegree = new int[numCourses];

        for(int i = 0; i<numCourses; i++){
            for(int v : AL[i]){
                indegree[v]++;
            }
        }

        Queue<Integer> q = new LinkedList<>();

        for(int i = 0; i<numCourses; i++){
            if(indegree[i] == 0){
                q.add(i);
            }
        }

        int c = 0;

        while(!q.isEmpty()){
            int node = q.poll();
            c++;

            for(int v : AL[node]){
                indegree[v]--;
                if(indegree[v] == 0){
                    q.add(v);
                }
            }
        }

        return c==numCourses;
    }
}
```
