## Problem  
You’re given an `n x n` matrix `isConnected` where:

isConnected[i][j] = 1 → city i is directly connected to city j

Return the number of **provinces** (connected components).  
  
---  
  
## Approach (DFS)  
  
Treat the matrix as a graph:  
- Each city = node  
- If `isConnected[i][j] == 1` → edge between i and j  
  
Algorithm:  
1. Maintain a `visited[]`  
2. For each city:  
   - If not visited → start DFS  
   - Mark all reachable cities  
   - Increment count  
  
---
```java
class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        boolean[] visited = new boolean[n];
        int c =  0;
        for(int i = 0; i<n; i++){
            if(!visited[i]){
                dfs(visited, isConnected, i);
                c ++;
            }
        }
        return c;
    }

    private void dfs(boolean[] visited, int[][] isConnected, int city){
        visited[city] = true;
        for(int i = 0; i<isConnected.length; i++){
            if(isConnected[city][i] == 1 && !visited[i]){
                dfs(visited, isConnected, i);
            }
        }
    }
}
```
