## Problem  
There are `n` cities. Some of them are connected directly, while others are connected indirectly.  
  
If city `a` is connected to city `b`, and city `b` is connected to city `c`, then city `a` is indirectly connected to city `c`.  
  
A **province** is a group of directly or indirectly connected cities.  
  
Given an `n x n` matrix `isConnected`, return the **total number of provinces**.  
  
## Approach  
Treat the matrix as a **graph adjacency matrix**.  
  
1. Each city is a node.  
2. If `isConnected[i][j] == 1`, there is an edge between city `i` and city `j`.  
3. Traverse the graph using **Depth First Search (DFS)**.  
4. Every time we encounter an **unvisited city**, it means a new province starts.  
5. Perform DFS to mark all connected cities as visited.  
  
The number of DFS calls equals the number of provinces.

```java
class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        boolean[] visited = new boolean[n];
        int c =  0;
        for(int i = 0; i<n; i++){
            if(!visited[i]){
                dfs(visited, isConnected, i);
                c ++;
            }
        }
        return c;
    }

    private void dfs(boolean[] visited, int[][] isConnected, int city){
        visited[city] = true;
        for(int i = 0; i<isConnected.length; i++){
            if(isConnected[city][i] == 1 && !visited[i]){
                dfs(visited, isConnected, i);
            }
        }
    }
}
```
