## Problem  
Given an integer array `height` where each element represents the height of a vertical line, find two lines that together with the x-axis form a container that holds the maximum water.
___
## Approach  
Use the **Two Pointer technique**.  
  
- Start with two pointers at the beginning and end of the array.  
- Calculate the area using the width between pointers and the minimum height.  
- Move the pointer with the **smaller height inward**, since moving the taller one cannot increase the area.  
- Continue until the pointers meet.
___

```java
class Solution {
    public int maxArea(int[] height) {
        int r = (height.length)-1;
        int l = 0;
        int m_a = 0;
        while(l<r){
            int w = r-l;
            int h = Math.min(height[l], height[r]);
            int a = h*w;
            m_a = Math.max(m_a, a);
            if(height[l]<height[r]){
                l+=1;
            }
            else{
                r-=1;
            }
        }
        return m_a;
    }
}
```
