## Problem  
Given a string `s`, return the **longest palindromic substring** in `s`.  
A **palindrome** is a string that reads the same forward and backward.

## Approach: Expand Around Center

A palindrome mirrors around its center.  
For each character, we expand outward to check for palindromes.

Two cases are considered:
1. Odd length palindrome (center at one character)
2. Even length palindrome (center between two characters)

For every index i:
- Expand from (i, i) for odd length
- Expand from (i, i+1) for even length
- Track the longest palindrome found

class Solution {
    public String longestPalindrome(String s) {
        if(s == null || s.length() == 0) return "";
        int start = 0, end = 0;
        for(int i = 0; i<s.length(); i++){
            int odd = pal(s, i, i);
            int even = pal(s, i, i+1);
            int len = Math.max(odd, even);

            if(len > end - start){
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }
        return s.substring(start, end + 1);
    }
    private int pal(String s, int l, int r){
        while(l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)){
            l--;
            r++;
        }
        return r - l - 1;
    }
}
