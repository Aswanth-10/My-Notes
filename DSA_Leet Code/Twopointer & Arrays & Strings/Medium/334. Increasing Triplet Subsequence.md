## Problem  
Given an integer array `nums`, return **true** if there exists a triplet `(i, j, k)` such that:  

i < j < k  
nums[i] < nums[j] < nums[k]
  
Otherwise return **false**.  
  
---  
## Approach  
  
Track the **smallest** and **second smallest** numbers.  
  
Variables:  
  
- `n1` → smallest number  
- `n2` → second smallest number  
  
Steps:  
  
1. If `i <= n1` → update smallest  
2. Else if `i <= n2` → update second smallest  
3. Else → found a number greater than both → triplet exists  
  
Example:  

nums = [2,1,5,0,4,6]

n1 = 1  
n2 = 4  
6 > 4 → triplet exists

---

```java
class Solution {
    public boolean increasingTriplet(int[] nums) {
        int n1 = Integer.MAX_VALUE;
        int n2 = Integer.MAX_VALUE;

        for(int i : nums){
            if(i <= n1) n1 = i;
            else if(i <= n2) n2 = i;
            else return true;
        }
        return false;
    }
}
```
