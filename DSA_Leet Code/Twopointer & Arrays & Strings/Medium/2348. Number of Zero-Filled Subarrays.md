## Problem  
Given an integer array `nums`, return the number of **subarrays filled entirely with 0**.  
  
A **subarray** is a contiguous non-empty sequence of elements.  

---  

## Approach  
  
Count **consecutive zeros**.  
  
Let:  
- `s` = current streak of zeros  
- `n` = total number of zero-filled subarrays  
  
Whenever we encounter `0`:  

s++  
n += s

  
Why this works:  
  
If we have `k` consecutive zeros:  

0  
0 0  
0 0 0

  
Number of subarrays =  

k * (k + 1) / 2

  
Instead of calculating the formula, we accumulate it dynamically.  
  
Example:  

nums = [0,0,0]

Step 1 → s=1 → n=1  
Step 2 → s=2 → n=3  
Step 3 → s=3 → n=6

---

```java
class Solution {
    public long zeroFilledSubarray(int[] nums) {
        long n = 0;
        long s = 0;
        for(int i : nums){
            if(i==0){
                s++;
                n += s;
            }else{
                s = 0;
            }
        }
        return n;
    }
}
```
