## Problem  
Write a function to find the **longest common prefix string** among an array of strings.  
  
If there is no common prefix, return an empty string `""`.  
  
---  
  
## Approach  
  
1. Find the **length of the shortest string**.  
2. Compare characters **column by column** across all strings.  
3. If any mismatch occurs, return the prefix up to that index.  
4. If all characters match, return the prefix of the shortest string.  
  
This works because the prefix cannot be longer than the shortest string.
___

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        int m = Integer.MAX_VALUE;
        for(String s:strs){
            if(s.length()<m){
                m=s.length();
            }
        }
        int i=0;
        while(i<m){
            for(String s:strs){
                if(s.charAt(i)!=strs[0].charAt(i)){
                    return strs[0].substring(0,i);
                }
            }
            i++;
        }
        return strs[0].substring(0,i);
    }
}
```
