# Two Pointers Pattern

## Idea

Use two indices to traverse a data structure efficiently.

Often used to:
- compare elements
- shrink search space
- process sorted arrays

---

## Types

### Same Direction
Both pointers move forward.

Example:
Remove duplicates from sorted array.

### Opposite Direction
One pointer from start, one from end.

Example:
Two Sum II.

### Fast & Slow Pointer

Example:
Cycle detection.
