## Problem  
Given `n` non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

## Approach  
Use the **Two Pointer technique**.  
  
- Maintain two pointers `l` and `r` at the start and end.  
- Track the maximum height seen so far from the left (`m_l`) and right (`m_r`).  
- If `height[l] <= height[r]`, process the left side:  
- If current height is smaller than `m_l`, water can be trapped.  
- Otherwise update `m_l`.  
- Otherwise process the right side similarly.  
  
This works because the trapped water depends on the **smaller boundary**.

```java
class Solution {
    public int trap(int[] height) {
        int l = 0;
        int r = height.length -1;
        int m_l = 0;
        int m_r = 0;
        int ans = 0;

        while(l<=r){
            if(height[l] <= height[r]){
                if(height[l] >= m_l){
                    m_l = height[l];
                }else{
                    ans += m_l - height[l];
                }
                l++;
            }else{
                if(height[r] >= m_r){
                    m_r = height[r];
                }else{
                    ans += m_r - height[r];
                }
                r--;
            }
        }
        return ans;
    }
}
```
