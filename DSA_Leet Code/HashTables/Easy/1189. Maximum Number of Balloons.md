## Problem  
Given a string `text`, return the maximum number of times you can form the word:  "balloon"
Each character can be used only once.  

---
## Approach  
  
Count occurrences of characters needed for `"balloon"`:  
Required:
b → 1  
a → 1  
l → 2  
o → 2  
n → 1

Steps:  
1. Count characters using a HashMap  
2. Compute how many times each required character can form "balloon"  
3. Take the minimum of all counts  
 
Important: l and o must be divided by 2

---
```java
class Solution {
    public int maxNumberOfBalloons(String text) {
        HashMap<Character,Integer> map = new HashMap<>();
        String a = "balloon";
        for(char c : text.toCharArray()){
            if(a.indexOf(c)!=-1){
                map.put(c, map.getOrDefault(c,0)+1);
            }
        }
        if(!map.containsKey('b') || !map.containsKey('a') || !map.containsKey('l') || !map.containsKey('o') || !map.containsKey('n')){
            return 0;
        }else{
            return Math.min(Math.min(map.get('b'), map.get('a')), Math.min(map.get('l')/2, Math.min(map.get('o')/2, map.get('n'))));
        }
    }
}
```
