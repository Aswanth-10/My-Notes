# 📘 Obsidian Keyboard Shortcuts

## 🧭 Navigation

- **Cmd + O** → Open another note
    
- **Cmd + P** → Command palette
    
- **Cmd + E** → Toggle Edit / Preview mode
    
- **Cmd + Click** → Open link in new pane
    
- **Cmd + Alt + ← / →** → Navigate back / forward
    

---

## ✍️ Editing

- **Cmd + B** → Bold text
    
- **Cmd + I** → Italic text
    
- **Cmd + Shift + K** → Insert link
    
- **Cmd + K** → Insert internal link
    
- **Cmd + D** → Delete line
    
- **Cmd + Enter** → Follow link under cursor
    

---

## ✅ Task / Checkbox

- `- [ ] Task` → Create checkbox
    
- `- [x] Task` → Completed task
    
- **Cmd + L** → Toggle checkbox
    

Example:

-  Learn Git
    
-  Setup Obsidian Git
    
-  Install Obsidian
    

---

## 🔗 Linking Notes

- `[[Note Name]]` → Link to another note
    
- `[[Note Name|Alias]]` → Custom link text
    
- `![[Note Name]]` → Embed note

## 📦 Callouts (Important Boxes)

```
> [!note]
> Important note here
```

Other callouts:

```
> [!tip]
> Helpful tip

> [!warning]
> Warning message

> [!important]
> Very important point
```

## 🔎 Search

- **Cmd + F** → Search in current note
    
- **Cmd + Shift + F** → Search across vault
    

---

## 📁 File Operations

- **Cmd + N** → Create new note
    
- **Cmd + Shift + N** → New folder
    
- **Cmd + Delete** → Delete note
